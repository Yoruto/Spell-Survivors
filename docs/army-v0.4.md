# 赤旗军团 v0.4

本次根据用户要求，移除虫状近战怪，将普通敌人改为 Dota 2 / LoL 式人形兵线单位，并将 Boss 改为以重装巨斧英雄为造型原型的赤斧统帅。

参考入口：[Dota 2 斧王](https://www.dota2.com/hero/axe)、[LoL 德莱厄斯](https://www.leagueoflegends.com/en-us/champions/darius/)。取材于重装战士、巨斧、战袍、肩甲及强壮人体的视觉方向，使用本项目原创程序绘制，不是直接导入原版模型，也不声称完整复刻两位英雄的技能。

## 小兵

- 赤旗剑盾兵：双足站立、钢盔、红缨、红色战袍、胸甲、护胫、长剑及带金属纹饰的盾牌。删除旧造型的尾巴、四肢爬行动作、背刺和兽首。
- 赤旗法师兵：同阵营的红色短袍、兜帽、面部眼睛和水晶法杖，施法时抬手与水晶发光，脚下保留法力条。删除旧祭司的悬浮书本造型。
- 近战挥剑只在实际提交接触攻击后触发，暂停及商店中冻结，不增加攻击次数或改变攻击距离。

## 赤斧统帅

- 人类面孔、短黑发、浓眉、胡须，取消原来的骷髅面孔、骨角和胸口魔法核心。
- 黑铁重甲、宽肩甲、肌肉前臂、深红战袍与披风，双手握持带银色刃口的巨斧。
- 原有延迟地面攻击改用举斧蓄力、斧头图案预警及落斧斩痕来表现。
- 原有十二发环形弹幕改为旋转飞斧，速度、伤害和法力消耗不变。
- 半血后保留原有加速节奏，以红色气息和斧刃余烬表示狂暴。
- Boss 名称、血条色彩和结算相关文本同步更新；试炼场仍能直接召唤。

## 实现与验证

敌军绘制集中到 `src/enemies.js`，小卡尔仍由 `src/actors.js` 绘制。伤害和碰撞仍由独立战斗引擎控制。模型左右面向、挥剑、举斧蓄力、狂暴、飞斧和落斧效果纳入绘制检查；接触攻击与弹丸的回归测试校验动画标记没有改动实际攻击规则。浏览器验证同屏小兵、统帅、预警和运行日志。
