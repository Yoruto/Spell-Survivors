# 《咒语幸存者》核心玩法与法术系统设计规格 v0.1

> 项目：Spell-Survivors  
> 日期：2026-10-23  
> 状态：核心交互及十种法术的机制方向已确认；具体数值、敌人配置、商店商品和关卡节奏待设计。  
> 用途：开发实现、测试用例与后续版本规划的共同基准。

## 1. 游戏定位与基本流程

《咒语幸存者》是一款以《吸血鬼幸存者》式怪潮生存为基础、以《Dota 2》祈求者（Invoker）式元素组合为核心攻击操作的动作 Roguelite 游戏。玩家主动输入咒语，在移动与躲避怪物的同时施放法术；商店强化改变已有技能的强度与表现。

已确认的基础流程：

1. 选择角色。
2. 进入关卡，移动、组合施法并清理怪潮。
3. 进入商店强化角色或法术。
4. 挑战 Boss。
5. 通关结算。

每局具体时长、商店出现次数、怪潮波次、角色差异和局外成长尚未决定。本文件不为这些内容擅自设定数值。

## 2. 核心操作规则（已确认）

| 项目 | 规则 |
| --- | --- |
| 移动 | 鼠标右键点击地面，角色前往点击位置 |
| 连续调整移动 | 按住右键时持续更新目的地；松开后继续前往最后指定的目的地 |
| 元素输入 | Q / W / E，分别暂定为冰 / 雷 / 火 |
| 组合槽 | 始终保留最近输入的三个元素，先进先出（FIFO） |
| 组合顺序 | 只比较元素种类和数量，不比较顺序 |
| 基础咒语 | 三元素、三槽共十种组合，开局全部可用 |
| 施法 | 按 R 立即尝试释放当前组合对应的法术，无额外「祈唤后再按技能槽」步骤 |
| 施法后 | 元素组合不清空，允许对同一法术再次按 R |
| 冷却 | 每种法术独立冷却；没有公共施法冷却 |
| 移动施法 | 允许边移动边组合和释放法术，普通施法不强制停步 |
| 瞄准 | 需要方向、位置或单位的法术均由鼠标确定，不替玩家自动挑选施法目标 |
| 自身施法 | 幽灵漫步、熔炉精灵等自身施法不需要鼠标指定目标 |
| 常规攻击 | 核心攻击方式为主动咒语；右键点击敌人不自动触发额外普通攻击 |

### 2.1 组合队列与施法

- 初始队列为空。Q/W/E 每次有效按下将一种元素压入队尾；超过三格则移除最早的元素。
- 例如 QQQ 后输入 W，队列变为 QQW；QQW、WQQ、QWQ 对应同一法术。
- 元素不足三个时按 R 不施法。
- 成功施法不清空队列；冷却中的法术按 R 不会施放，也不自动排队等待冷却完成。
- 施法失败保留队列，不消耗该法术冷却。
- 按键以一次有效 key-down 为准；操作系统长按键的重复输入不应自动连发元素或 R。
- 连续释放不同已冷却法术不应被额外的全局间隔拦截。
- 在 R 被处理的瞬间记录队列、玩家位置和鼠标目标。已经生成的投射物或区域不因随后移动鼠标而改变方向或落点（除非某技能明确具有追踪能力）。

### 2.2 目标与射程的统一约定

- **单位目标**：鼠标指向有效单位且单位处于合法射程内时成功施法；指向空地、无效单位或射程外单位时失败，不消耗冷却。
- **方向法术**：使用角色到鼠标位置的方向发射；例如普通直线投射物朝该方向运动，到最大射程时终止，不要求鼠标位置处于射程内。
- **地面法术**：鼠标确定有效地面落点；普通地面法术超射程时落点截断到射程边缘。
- **自身法术**：直接作用于玩家或在玩家附近生成召唤物，无需额外鼠标确认。
- **阳炎冲击特例**：没有普通施法距离上限，但目前只能指定当前可见战场内的有效位置；不引入独立的全图瞄准界面。
- 瞄准点落在 UI 或无效地图区域时不应误对游戏世界施法。
- 普通实体投射物默认受不可通行场景障碍阻挡；穿墙、穿透或特殊地面效果由具体技能逐项覆盖。寒冰之墙自身不是实体障碍。
- 成功释放的方向或范围法术即使命中零个敌人，也正常进入冷却。

## 3. 十种基础咒语

以下组合、名称和核心作用以卡尔原版十技能为开发原型；《咒语幸存者》采用 **QWE + R 直接施法**，不照搬 Dota 2 的祈唤技能槽操作、元素技能等级和具体平衡数值。

| 组合 | 原型名 | 施法类型 | 核心功能 |
| --- | --- | --- | --- |
| QQQ | 急速冷却 / Cold Snap | 敌方单位 | 受伤触发短暂硬直和额外伤害 |
| QQW | 幽灵漫步 / Ghost Walk | 自身 | 隐身，减速周围敌人 |
| QQE | 寒冰之墙 / Ice Wall | 方向 | 生成可穿越的减速、持续伤害冰墙 |
| QWW | 强袭飓风 / Tornado | 方向 | 前进的龙卷风吹起敌人；浮空无敌，落地伤害 |
| WWW | 电磁脉冲 / E.M.P. | 地面 | 延迟爆炸造成基础范围伤害，并消耗有法力敌人的法力 |
| WWE | 灵动迅捷 / Alacrity | 自身或友方召唤物 | 玩家增加法术伤害及冷却恢复；召唤物增加攻击力及攻速 |
| QWE | 超震声波 / Deafening Blast | 方向 | 声波伤害、击退、缴械 |
| QEE | 熔炉精灵 / Forge Spirit | 自身召唤 | 召唤可独立攻击且能削减护甲的元素生物 |
| WEE | 混沌陨石 / Chaos Meteor | 地面加方向 | 陨石落下后继续向前滚动，造成持续伤害与灼烧 |
| EEE | 阳炎冲击 / Sun Strike | 地面 | 指定位置延迟爆发；总伤害在有效命中目标之间均分 |

### 3.1 QQQ 急速冷却

- 对鼠标指向的有效敌方单位施加持续状态。
- 目标受到玩家有效法术伤害或己方召唤物有效攻击伤害时，可触发额外冰霜伤害和短暂硬直。
- 持续伤害的有效伤害事件也可触发，但每个目标存在独立的最小触发间隔；该间隔的具体数值待平衡。
- 急速冷却自身追加的伤害 **不能再次触发急速冷却**，以防止无限递归。
- 免疫伤害或未产生有效伤害的事件不触发；如何细分生命伤害与护盾伤害，留待伤害系统确定。
- 目标处于强袭飓风的浮空无敌期间，不通过普通伤害触发；落地后恢复判断。
- Boss 不承受反复硬直，但照常承受符合条件的追加伤害。

### 3.2 QQW 幽灵漫步

- 自身进入隐身状态，并持续减速身边的敌人。
- 右键移动或输入 Q/W/E 不会破隐；**成功释放其他法术时立即破隐**。失败的施法不破隐。
- 已经存在的持续伤害和此前召唤的熔炉精灵继续造成伤害，不视为玩家新施法，不因此破隐。
- 隐身阻止普通怪物重新直接索敌；敌人可向玩家最后出现的位置行动。
- 隐身不是无敌：已有投射物、范围攻击和环境伤害仍可能命中。
- 自身移速修正、隐身持续时间、减速半径及冷却数值待平衡。

### 3.3 QQE 寒冰之墙

- 以鼠标方向确定面向，在角色前方生成一段与施法方向相对应的冰墙区域。
- 冰墙对经过或停留的敌人施加减速与持续伤害。
- **不是实体阻挡**：玩家、敌人和允许通过的单位均可穿过；冰墙不改变寻路地图的可通行性。
- 同时命中多个减速区域时应用最高减速值，具体数值待平衡。

### 3.4 QWW 强袭飓风

- 向鼠标方向发出移动的龙卷风，作用于沿途敌人。
- 普通敌人被吹起后不能行动，**浮空期间无敌**；落地时结算对应伤害。
- 浮空单位不能作为普通伤害与阳炎冲击伤害分摊的有效目标；连招需要预判落地时机。
- Boss 免疫浮空及强制位移，仍承受该法术对应的有效伤害。
- 龙卷风的移动距离、宽度、浮空时间和落地伤害尚未确定。

### 3.5 WWW 电磁脉冲

- 在鼠标指定位置生成电磁区域，延迟后爆炸。
- **所有有效敌人均受到基础爆炸伤害**，即使它们没有魔法值。
- 拥有魔法值的敌人额外受到法力削减效果；不要求所有普通怪物都具备法力资源。
- 是否向玩家返还法力，取决于未来是否引入玩家法力系统；目前不把该效果纳入已确认机制。
- 爆炸延迟、范围、基础伤害和法力削减量待定。

### 3.6 WWE 灵动迅捷

- 如果鼠标指向有效友方熔炉精灵，则增强该召唤物的攻击力和攻击速度。
- 没有指向有效友方召唤物时，默认增强玩家自身的**法术伤害及独立冷却恢复速度**。
- 不新增普通攻击系统，不自动按键，不改变实际 Q/W/E/R 输入速度，也不产生公共冷却。
- 冷却恢复加速只在增益生效期间影响冷却进度；具体计算倍率和叠加限制在数值阶段确定。

### 3.7 QWE 超震声波

- 向鼠标方向释放前进的声波，对命中敌人造成伤害、击退和缴械。
- 缴械禁止普通攻击，**不等同于沉默**，敌人仍可执行未被其他状态禁止的技能行为。
- 击退遵守地图可通行边界，不会把单位推进墙体。
- Boss 不受强制位移；缴械持续时间减半，伤害正常生效。

### 3.8 QEE 熔炉精灵

- 在玩家附近召唤有独立生命值、可受攻击、存在时间有限的元素生物。
- 召唤物自动跟随玩家并在范围内选择敌人攻击；无需玩家额外微操。这是召唤物 AI，而不是玩家法术的自动索敌。
- 熔炉精灵攻击能够触发目标已有的急速冷却，并可持续叠加有上限的护甲削减。
- 初始同时存在上限 **1只**；商店可以把上限强化到 **2只**。
- 达到上限后成功再次召唤时，替换最早召唤的旧单位；旧单位消失或死亡会释放名额。
- 熔炉精灵可接受灵动迅捷的攻击力及攻击速度增益。
- 具体生命、攻击、追踪范围、护甲削减上限和持续时间待定。

### 3.9 WEE 混沌陨石

- 鼠标指定陨石落点；短暂延迟后陨石落下，沿释放时「玩家位置 → 落点」确定的方向滚动。
- 施法成功后，即使玩家移动或转动鼠标，陨石仍沿已经确定的方向行进。
- 陨石能够穿过敌人，对沿途敌人反复造成伤害，并施加灼烧；同一目标每次受击应有最小伤害间隔。
- 同来源的灼烧重复施加时刷新持续时间，不无限增加同名层数。
- 陨石达到最大滚动距离或地图边界时终止；与特殊场景障碍物的交互可由具体技能规则覆盖。
- 落下延迟、滚动长度和伤害频率待定。

### 3.10 EEE 阳炎冲击

- 鼠标指定当前可见战场内任意有效地面位置，没有普通施法距离上限。
- 延迟后在指定区域造成一次高额伤害。
- **保留原版均分机制**：本次总伤害在所有实际可受击的命中敌人之间平均分配；不设置三目标上限，也不对精英/Boss 私自采用独立倍率。
- 浮空无敌或其他无效单位不参与有效命中及伤害分摊。
- 面对大量普通怪物时，Boss 可能分到较少的伤害。这是本次明确保留的玩法取舍，不能在实现时悄悄改成每目标全额伤害。
- 延迟、伤害总量和范围半径待平衡。

## 4. Boss 控制抗性（已确认）

Boss 受伤害正常，但对强制行动控制具有统一抗性，避免被十种法术持续锁死。

| 效果类型 | 普通敌人 | Boss |
| --- | --- | --- |
| 减速 | 完整效果 | 减速效果减半 |
| 急速冷却短暂硬直 | 正常触发 | 免疫硬直，保留追加伤害 |
| 强袭飓风浮空 | 浮空且期间无敌 | 免疫浮空，结算有效伤害 |
| 超震声波击退 | 正常强制位移 | 免疫强制位移 |
| 缴械 | 正常持续时间 | 持续时间减半 |
| 灼烧和其他持续伤害 | 正常 | 正常 |
| 法力削减 | 有法力时生效 | 有法力时生效 |

精英怪的中间抗性、Boss 特殊免疫列表与具体数值尚未决定，后续须逐项定义，不能把上述 Boss 规则未经审核地套到所有精英。

## 5. 状态叠加与伤害事件

### 5.1 统一叠加规则

- **减速**：不同减速同时生效时只取最高的减速比例，不相加、不相乘。
- **同来源灼烧**：重复施加刷新持续时间，不无限叠层；不同来源的持续伤害可以独立结算。
- **护甲削减**：熔炉精灵可通过多次命中累积削甲，但必须设置可配置的叠加上限。
- **急速冷却**：有效伤害源可触发，但必须遵守同目标触发间隔，且追加伤害不允许递归触发。
- **无敌与目标合法性**：先判断目标是否可受击，再进行伤害与需要有效受击才能触发的后续效果。
- **技能间无共享冷却**：灵动迅捷的冷却恢复增益不能被实现成公共施法间隔。

### 5.2 建议统一事件顺序

一次按 R 的处理顺序：

1. 读取三元素队列并解析法术。
2. 判断角色状态、该法术独立冷却和所需目标是否有效。
3. 如果无法施放，给出反馈，不消耗冷却、不清空队列、不触发成功施法导致的破隐。
4. 如果可以施放，记录鼠标目标、施法者位置及方向；提交成功施法事件并开始该法术冷却。
5. 若此前处于幽灵漫步且施放的是其他法术，立即破隐。
6. 生成投射物、区域、增益、状态或召唤物，并在命中/计时事件时结算后续效果。

伤害结算须能识别伤害来源、同来源持续效果、召唤物归属、目标无敌状态和「不可触发急速冷却」的追加伤害标记。

### 5.3 必测连招

- **急速冷却 + 熔炉精灵**：召唤物每次有效攻击可按触发间隔激活急速冷却，不产生递归。
- **急速冷却 + 混沌陨石**：陨石的有效持续伤害可触发急速冷却，但受独立触发间隔限制。
- **强袭飓风 + 混沌陨石**：浮空期间无敌，需要按落地时机命中。
- **强袭飓风 + 阳炎冲击**：浮空敌人不参与无敌期间的受击或伤害分摊。
- **幽灵漫步 + 熔炉精灵**：已存在的召唤物攻击不会破隐；成功重新施放其他法术会破隐。
- **灵动迅捷 + 熔炉精灵**：友方召唤物使用攻击增益；对玩家自身则使用法术增益。
- **寒冰之墙 + 幽灵漫步**：同时减速时取最高值，不能通过叠加把敌人永久锁定。

## 6. 商店强化方向

已确认：玩家开局可使用十种基础法术，商店以强化、改造现有技能为主，不靠逐步解锁基本组合支撑成长。

本阶段确认的唯一明确容量成长：

- 熔炉精灵的同时存在上限初始为1，可在商店强化至2。

其他可规划但**尚未确定数值、稀有度和上限**的强化维度：

1. 法术伤害、冷却、范围、持续时间等数值强化。
2. 幽灵漫步的移速、减速光环和持续时间变化。
3. 急速冷却触发间隔或追加效果强化。
4. 电磁脉冲的范围、法力削减和特殊牵引。
5. 灵动迅捷的增益强度与持续时间。
6. 陨石与阳炎的落点、轨迹、范围或其他机制变体。

不得把这些方向误写成已经确定的商品列表。商店出现频率、商品数量、价格、刷新和重复购买规则全部待后续讨论。

## 7. UI 与操作反馈要求

- 战斗界面实时显示三个元素槽、当前解析出的法术和施法失败原因。
- 鼠标指向有效单位时，对单位目标技能提供清晰的可选目标反馈；方向及地面技能显示必要的方向/落点信息。
- 独立冷却必须能够查询，尤其在十种法术全部已解锁的情况下，避免玩家只能靠反复按 R 判断可用性。
- 清楚反馈隐身剩余时间、破隐、Boss 控制免疫、浮空无敌、急速冷却触发和阳炎伤害分摊。
- 召唤物数量上限及当前存活数量应可见；灵动迅捷的实际受益对象需要明确提示。
- 在商店、暂停、结算和 UI 交互状态下，键盘及鼠标事件不得误触发战斗行为。
- 对于超射程或无效目标，反馈应与技能类型一致：方向技能射程截断、地面技能落点截断、单位技能目标无效则不施放。

## 8. 尚未冻结的事项

本文件不包含完整平衡表。以下项目不得在开发过程中被误认为已经由设计审核确认：

- 生命值、伤害属性、法术强度、护甲和伤害减免公式。
- 所有十种法术的确切伤害、冷却、范围、持续时间、施法前摇、投射物速度、状态触发间隔和成长曲线。
- 敌人法力资源及法力削减与特殊施法 AI 的具体联系。
- 灵动迅捷冷却恢复速度的数值及与未来其他冷却强化的叠加公式。
- 熔炉精灵 AI 的感知半径、寻路、仇恨、单位碰撞、生命与攻击成长。
- 精英怪的控制抗性、Boss 具体种类与例外规则。
- 特殊法术穿墙、障碍物和复杂地图结构的细则。
- 角色系统、关卡时长、商店频次、商品池、价格与局外成长。
- HUD 的最终布局、美术表现、音效和辅助输入方式。

这些内容可以在原型制作中使用显式标注的测试值，但不得用测试值覆盖本文件中的机制决策。

## 9. 开发验收检查清单

- [ ] 三格 FIFO 队列正确更新；三个元素顺序无关，且恰好能识别十种组合。
- [ ] 十种基础法术开局都可施放；R 直接施法，成功后仍保留组合。
- [ ] 没有公共冷却；每种法术独立计时；按住 R 不因按键重复而自动连发。
- [ ] 右键点击/按住移动正确；移动与 QWE/R 施法可同时执行。
- [ ] 鼠标单位、方向、地面和自身目标分类正确；无效目标不消耗冷却。
- [ ] 方向投射物按最大射程截断，普通地面法术超射程截断，阳炎仅要求当前可见战场有效落点。
- [ ] 幽灵漫步在成功施放其他法术时破隐；仅切元素、既有 DoT 或召唤物攻击不破隐。
- [ ] 寒冰之墙可穿越，对区域内敌人持续伤害与减速，且不改变地图寻路阻挡。
- [ ] 强袭飓风浮空单位无敌；落地伤害正常，Boss 不受浮空。
- [ ] 电磁脉冲对无魔法敌人仍造成基础伤害，对有魔法敌人额外削减法力。
- [ ] 灵动迅捷对玩家与友方召唤物分别采用正确增益；无公共冷却副作用。
- [ ] 熔炉精灵自动攻击且能触发急速冷却；初始1只、强化后2只，满员重新召唤替换最早单位。
- [ ] 超震声波正确造成伤害、击退与缴械；Boss 位移免疫，缴械持续时间减半。
- [ ] 混沌陨石落点、滚动方向固定，重复伤害与灼烧不会产生无上限叠层。
- [ ] 阳炎冲击对所有有效命中目标均分总伤害，无敌单位不参与分摊。
- [ ] 减速取最大值、同来源灼烧刷新、护甲削减有限叠加。
- [ ] 急速冷却追加伤害不递归；持续伤害和召唤物受触发间隔约束。
- [ ] 普通怪与 Boss 的控制免疫差异按第4节实现。
- [ ] 战斗输入不会在商店、暂停、死亡与结算界面意外生效。

## 10. 建议的下一轮规划

1. **数值与伤害基础**：确定敌人生命、法术强度、伤害类型与抗性模型，再建立十技能首版平衡表。
2. **商店强化设计**：确定每次商店商品数、价格、稀有度、刷新、购买上限，并逐技能设计强化池。
3. **战斗原型测试**：验证连续 QWE/R 输入、右键移动与鼠标瞄准的手感；重点测试大量敌人、十种独立冷却及高频效果的可读性与性能。
4. **关卡与 Boss**：确定怪潮规模、遭遇模板、Boss 招式和控制抗性例外。
5. **表现与商业化独立性**：卡尔十技能仅作为开发参照，正式发布前需使用独立的名称、图标、文本、特效和角色表现，不直接复制 Dota 2 的素材。
