# 小卡尔与战场美术 v0.3

根据用户要求，游戏改为只有一个角色「小卡尔」。营地不再提供角色选择，死亡和通关后的入口改为再来一局或返回营地。原有角色差异取消，小卡尔采用 120 生命、220 移速、100% 基础法伤，遗物成长保留。

## 视觉内容

- 小卡尔：白色翘发、大头比例、紫金法袍、高领和肩甲，皮肤与头发渐变材质。左右面向、行走步态、披风摆动、呼吸和抬手施法均跟随战斗时钟。
- 三颗元素球环绕身体前后交替，冰晶、闪电、火焰各自具有符号与材质。尚未输入的槽位对应暗色装饰球，实际施法仍严格依赖 HUD 的三格输入队列。
- 营地插画和头像使用 `assets/carl.svg`，战斗造型由 `src/actors.js` 绘制，均为原创矢量图形，不依赖外部贴图。
- 裂隙猎爪：四肢、爪尖、背部骨刺、尾巴、发光眼睛和行走步态。
- 兜帽祭司：深色兜帽、眼睛、破损长袍、书页、手部法球及抬手动作，脚下显示剩余法力。
- 裂隙领主：分层胸甲、发光核心、骨角头盔、骷髅面孔、肩甲、利爪、破损披风和符文底座。蓄力时手部发光，半血后核心转为红色并冒出火焰，仍按原机制加速施法。
- 熔炉精灵补充焦炭外壳、发光眼睛、熔岩胸核、手部火焰。敌方弹丸增加拖尾、旋转碎晶和高亮核心。
- 普通怪入场符文、击杀碎片、Boss 入场波纹和地面攻击的收束法阵同步更新。

## 绘制与交互

玩家、敌人和精灵按世界 Y 坐标排序，减少前后遮挡错误；地面法阵和命中效果先绘制，陨石与天火光柱再绘制前景层，最后显示伤害数字。表现状态只影响绘制，不增加攻击前摇，不改变独立冷却及命中伤害规则。

单位目标技能额外接受鼠标指向祭司兜帽和 Boss 骷髅面部，不要求只能点击脚下的碰撞圆。实体伤害碰撞半径保持原值；浮空单位仍不可选且无敌。

所有动画取战斗时钟，暂停及商店冻结动作。重开清空步态、施法动作和遗物状态。没有使用定时器累积动画，也不引入远程资源服务。

## 试炼 Boss

进入遗物试炼后，可用「召唤试炼 Boss」直接生成一个领主。已有存活领主时按钮禁用；暂停、商店、正常远征不允许此操作。试炼击败 Boss 后继续游戏，可再次召唤，退出试炼后清空。角色免伤规则只在试炼中生效。

## 验证

`npm test` 覆盖单角色状态、重开清理、试炼 Boss 隔离、动作暂停、可见模型目标选择，以及模型双向、施法和狂暴形态绘制时所有数值坐标有效；原有十技能和十五件遗物回归测试继续执行。`npm run build` 同时复制模型代码和 SVG 素材。
