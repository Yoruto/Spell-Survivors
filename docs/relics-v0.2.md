# 遗物与特效 v0.2

> 本文保留历史机制与数值。当前商店已改为三栏各随机三项、金币购买；角色遗物已归入单槽被动装备，无免费遗物。当前规则见 [三类商店 v0.7](design/shop-v0.7.md)。

本次扩展根据用户要求加入角色/技能遗物，并参考祈求者跨版本天赋、神杖及魔晶的机制方向。属于本作改编，**不是对 Dota 2 当前补丁的精确复刻**。原型数值可继续调整。官方机制背景：[祈求者英雄页](https://www.dota2.com/hero/invoker?l=schinese)、[7.07 天赋更新](https://www.dota2.com/duelingfates)。

## 商店规则

- 每次正常阶段商店获得一次免费遗物选择，任选未拥有遗物；也可花晶石购买，付费购买不消耗免费次数。
- 每件遗物本局限一次，无装备槽限制，已拥有遗物全部同时生效。重开后完整清空。
- 商店分为咒语遗物、角色遗物、基础补给三个标签。原有四种数值补给仍可重复购买；双生炉心归入遗物。
- 两次商店各重置为一次免费机会，未使用机会不累积。继续按钮旁会显示免费选择未使用。
- HUD 显示遗物收藏，点击可查看机制；秘典用星标标记被强化的技能，技能详情列出实际生效遗物。

## 特效

`src/vfx.js` 单独负责法术表现：紫色电磁球与收束电弧、强化后的旋涡牵引线；坠落陨石、旋转岩壳、熔岩裂纹、火焰与焦痕；白金天火柱、地面法阵、爆发和余烬；半透明立体冰晶墙与霜雾；灰白旋风漏斗与旋转碎屑；蓝白色声波及完整环形波；隐身薄雾、灵动电弧、熔火精灵与火弹、急速冷却冰晶和命中碎片。使用程序绘制的原创表现，没有使用原版游戏贴图或模型。

特效时间来自战斗时钟，暂停及商店中冻结。粒子按确定性时间函数绘制，不创建无限增长的粒子对象；法术伤害仍由战斗引擎独立结算。瞄准预览显示三陨石、三天火的实际落点和轨迹，以及强化 EMP 的实际范围。

## 试炼与验证

主菜单「进入遗物试炼」提供免伤角色和 9999 晶石，可随时打开试炼补给购买遗物，在真实输入和战斗系统中检查强化。试炼不触发正常阶段商店或 Boss；精灵仍可受伤。退出并重新开始正常远征后恢复正常伤害和经济规则。

`npm test` 包含基础机制及遗物机制测试；新增覆盖唯一购买、免费次数、阶段重置、牵引合法性、三轨迹、环形单次命中、天火均分、强化连招、吸血上限、重开清理和试炼隔离。浏览器实际检查购买、收藏、禁止重复购买、连续施法与运行日志。
