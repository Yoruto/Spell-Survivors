# 咒语幸存者 · Spell Survivors

## v0.5 架构与远征

架构决策、模块职责、技能强化契约和暂定数值见 [架构设计](docs/design/architecture-v0.5.md)。现在按「选择路线 → 关卡 / 事件 → 金币商店」循环，每轮完成 5 个节点后挑战 Boss，共 2 轮。事件计入节点，第一轮 Boss 后可购物，第二轮 Boss 后胜利。

货币统一为金币。商店分为属性提升、遗物提升、装备提升三栏，每栏独立随机 3 项。可花金币购买多项，购买后不补货；统一刷新从 10 金币开始，每次增加 5，下家商店重置。属性可重复成长，同类每次加价 5 金币；遗物本局唯一；主动和被动装备共用一个槽，购买新装备即移除旧装备，不返金币。完整数值见 [三类商店设计](docs/design/shop-v0.7.md)。

十种技能具有机器标签，属性计算与执行从 Game 拆出；范围提升现归入属性区；「复唱符印」仍为多重施法遗物，验证范围与多重施法组合。当前共 12 件机制遗物、6 类属性和 9 件装备。第一轮挑战斧王，第二轮挑战伐木机；事件先实现金币 / 治疗二选一。以下 v0.2–v0.4 段落保留版本历史，当前流程以本节为准。

## Boss 技能与 AI

两轮分别迎战**斧王 · 赤斧统帅**和**伐木机 · 锯齿暴君**。斧王拥有吼叫、反击螺旋、战斗饥渴和淘汰之刃，半血解锁跳斩与双旋转；伐木机拥有死亡旋风、锯链、活性护甲和飞轮，半血解锁两段锯链与双飞轮。

Boss 血条下方新增**蓝条**：初始 0 / 100，每秒恢复 5，满蓝后在当前动作与恢复窗口结束时优先释放大招并清空蓝量。普通技能不耗蓝，EMP 可削减 60 蓄能、推迟大招。招式均有预警与恢复窗口，护甲过热会提供易伤机会。详见 [Boss 技能、数值与验证](docs/design/bosses-v0.6.md)。

「进入遗物试炼」后可分别召唤斧王或伐木机，使用「测试半血狂暴」直接观察第二阶段；Boss 存活时暂停自动刷普通怪。

## 小兵技能与 AI

剑盾兵会分散接敌，抬剑 0.4 秒后向锁定方向挥砍；法师举杖施法、攻击后横移，被贴近时有限后撤，低蓝时原地回能；新增持长矛的突击兵，蓄力 0.8 秒后沿预警路径冲锋，结束后留出反击窗口。控制可中断相应动作。最后三只敌人阶段法师停止后撤，方便清场。

援军每六人为四名剑盾兵、一名法师和一名突击兵。遗物试炼新增「召唤小兵小队」，可直接观察行为。小兵定义、AI 和预警绘制已拆为独立模块；数值与控制规则见 [小兵技能与 AI 设计](docs/design/enemy-ai-v0.5.md)。旗手留作后续扩展。

## 单槽装备

营地可免费选择一件初始主动或被动装备，默认闪烁匕首。主动装备按 **空格** 使用，被动装备自动生效。主动与被动共用一个槽；商店购买会直接替换并移除旧装备，旧被动立即失效，无背包和免费换装。每件主动装备保留本局独立冷却，重新买回也不重置冷却；黑皇杖或中亚的效果结束后才能替换，暂停和商店冻结计时。被动装备包括赤晶血石（2.5% 有效伤害吸血）、复苏圣种（生命 +40、每秒恢复 1.5）、奥术王冠（基础法伤 +20%、冷却恢复 +15%）和风行秘靴（基础移速 +20%、吸取距离 220）。

| 装备 | 本游戏效果 | 冷却 |
| --- | --- | --- |
| 黑皇杖 | 6 秒控制免疫，解除已有控制，魔法减伤 80%；可移动施法，物理伤害正常 | 32 秒 |
| 中亚沙漏 | 无敌且免控 3 秒，期间无法移动、输入元素、施法或使用装备；敌人及已有法术继续运行 | 35 秒 |
| 闪烁匕首 | 向鼠标落点闪烁，最远 280，地图边界截断并取消旧移动指令 | 12 秒 |
| 希瓦的守护 | 周围 230 范围造成 70 伤害，减速 50% 持续 4 秒；Boss 减速减半 | 24 秒 |
| 梅肯斯姆 | 自身恢复 45 生命，周围 230 范围存活精灵恢复 35 生命，均不超上限 | 28 秒 |

以上为本游戏原型数值。近战攻击视为物理伤害，敌方法术弹丸及 Boss 地面法术视为魔法伤害。控制免疫统一通过 `Game.control` 判定，支持眩晕、定身、沉默与减速；目前敌人攻击尚不附加这些控制。闪烁无受伤禁用机制；无效落点与满血且无受伤精灵时的治疗不消耗冷却。装备配置位于 `src/equipment.js`，机制回归位于 `tests/equipment.test.mjs`。

基于 [核心设计规格](docs/design/spell-system-v0.1.md) 的可玩前端原型。原生 JavaScript + Canvas 2D，无框架或构建依赖。唯一角色为**小卡尔**，包含血量与死亡、右键移动、十种主动组合咒语、怪潮、拾取、商店、Boss、暂停及重开。战场和角色采用原创程序绘制。

## v0.4 赤旗军团与巨斧统帅

普通敌人已重做为 MOBA 小兵风格的**赤旗剑盾兵**和**赤旗法师兵**，采用同阵营红色战袍、金属装备，近战兵有挥剑动作，远程兵持水晶法杖。Boss 重做为参考斧王、德莱厄斯重装战士形象的**赤斧统帅**，具备人类面孔、胡须、披风、巨斧、举斧蓄力与红色狂暴表现；弹幕改为旋转飞斧。仍为本项目的原创二维矢量造型，战斗数值和控制抗性保持原规则。详见 [v0.4 美术说明](docs/army-v0.4.md)。

## v0.3 小卡尔与战场美术

移除多角色选择，直接由小卡尔出战。新增白色翘发、紫金法袍、三元素球、行走步态和抬手施法动作，并统一营地插画与 HUD 头像。重绘裂隙猎爪、兜帽祭司及骨角重甲领主；加入蓄力、半血狂暴、魔法弹拖尾和死亡碎片。角色按位置排序，天火光柱与陨石单独绘制前景层。

遗物试炼新增「召唤试炼 Boss」，可直接查看 Boss 的造型和招式，击败后可再次召唤。当前远征采用 v0.5 两轮路线流程。详见 [v0.3 实现说明](docs/art-v0.3.md)。

## v0.2 遗物与特效

新增 **15 件遗物**（11 件技能遗物、4 件角色遗物）：EMP 牵引、三重陨石、环形声波、三重天火、双精灵及其他强化。当时阶段商店每次可免费选择一件；当前改为金币购买与刷新。收藏栏和技能详情可随时查看效果。详见 [遗物机制与数值](docs/relics-v0.2.md)。

主菜单选择「进入遗物试炼」，可获得免伤角色及充足金币，通过「试炼补给」立即体验不同遗物组合。正常远征仍按原有阶段规则进行。

技能特效已独立重绘：电磁球与电弧、熔岩陨石与火尾、旋风漏斗、冰晶墙、天火光柱和环形声波；强化技能同步更新瞄准预览。

## 运行

需要 Node.js 20 或更新版本，无需安装 npm 依赖。

```sh
npm run dev
```

访问 http://127.0.0.1:5173 。可通过 `PORT` 环境变量修改端口。需要通过 HTTP 运行，不能直接双击 HTML 使用 ES Modules。

```sh
npm test       # 战斗机制和完整流程自动化验证
npm run build # 生成 dist/ 静态站点
node scripts/server.mjs --dist # 本地预览构建结果
```

## 部署到腾讯 EdgeOne Pages / Makers

本项目是纯静态站点。仓库根目录的 `edgeone.json` 已指定构建命令与产物目录：

| 设置 | 值 |
| --- | --- |
| 框架预设 | Other / 其他 |
| 根目录 | 仓库根目录（`./`） |
| 构建命令 | `npm run build` |
| 输出目录 | `dist` |
| Node.js | 20 或更新版本 |

Git 部署前，必须将 `index.html`、`style.css`、`layout.css`、`src/`、`assets/`、`scripts/`、`package.json` 和 `edgeone.json` 提交并推送到 EdgeOne 关联的分支。只在本机生成文件或提交设计文档，云端无法取得游戏入口。`dist/` 是生成目录，不需要提交，平台构建时会生成。

推送后在 EdgeOne 部署记录中确认构建成功，且部署提交包含以上文件，再从该记录重新打开预览链接。预览链接带鉴权参数时应完整复制；失效后从控制台获取新链接。直接上传部署则上传 `dist/` 的内容，确保上传根目录直接包含 `index.html`。

若出现平台的 `404 NOT_FOUND / The site does not exist`，先核对控制台当前部署域名；这表示平台没有找到对应站点，不能仅凭此错误认定是游戏 JavaScript 故障。若正确的新链接仍报错，检查项目域名状态和部署记录。参考 [官方错误码说明](https://pages.edgeone.ai/document/error-codes) 与 [部署排查指南](https://pages.edgeone.ai/document/troubleshooting)。

## 单屏布局

界面按窗口高度分配空间，战场占据主区域，生命、装备与元素施法合并为底部控制栏。左侧同时显示十个法术与遗物，试炼操作收纳在顶部「试炼工具」。页面、营地、技能说明和商店均无需滚动；试炼补给以翻页浏览全部商品。商品长说明保留在鼠标悬停提示中。布局规则位于 `layout.css`，构建时会一并复制到 `dist/`。

## 操作

| 操作 | 功能 |
| --- | --- |
| 鼠标右键点击 / 按住 | 移动 / 连续更新目标，松开继续到最后落点 |
| Q / W / E | 冰 / 雷 / 火，保留最近三个元素，组合顺序无关 |
| R | 按当前组合直接施法，组合保留；长按不会自动连发 |
| 空格 | 使用当前主动装备；闪烁匕首朝鼠标落点位移，长按不连发 |
| 鼠标位置 | 单位、方向及地面技能的瞄准依据 |
| Esc | 暂停 / 继续；关闭技能说明或指南 |
| H | 操作指南 |
| 左侧法术条目 | 查看详细机制，战斗自动暂停 |

建议先输入 `QEE` 再按 `R` 召唤熔炉精灵，再使用 `QWE` 声波、`WEE` 陨石和 `EEE` 阳炎攻击。`QQQ` 急速冷却需要鼠标指向射程内敌人。没有自动普通攻击，符合设计文档。音效默认关闭，可在右上角开启。切换窗口或隐藏页面自动暂停。

## 原型流程与数值

每轮选择 5 个路线节点，然后挑战 Boss，共两轮。怪潮 / 精英节点清理全部敌人后过关，无时间限制，奖励 35 / 65 金币；事件选择 30 金币或治疗。所有非最终关卡结算后进入商店，第二轮 Boss 击败后获胜。第一轮 Boss 为斧王（2400 生命），第二轮为伐木机（4800 生命）。

所有未冻结的数值和新增角色、商店商品都是**原型测试方案**，不修改原设计的已确认规则。角色与技能配置在 `src/config.js`；伤害、阶段和敌人行为在 `src/game.js`。详细平衡表见 [原型实现说明](docs/prototype-v0.1.md)。

## 文件

- `src/config.js`：小卡尔、十种法术和十二件机制遗物。
- `src/attributes.js` / `src/equipment.js`：属性成长、加价与上限、单槽装备和被动加成。
- `src/game.js`：独立于 DOM 的战斗、伤害、状态、敌人与流程协调。
- `src/spell-rules.js` / `src/spell-executor.js`：技能标签、强化计算与施法执行。
- `src/run.js` / `src/shop.js`：远征进度、商店库存与金币交易。
- `src/progression-view.js`：路线、事件与商店界面模板。
- `src/renderer.js`：地图、镜头、角色、怪物及法术预览。
- `src/vfx.js`：独立的法术粒子、光晕、闪电和火焰绘制。
- `src/actors.js`：小卡尔造型、元素球与角色绘制调度。
- `src/enemies.js`：剑盾小兵、法师小兵、赤斧统帅与敌方弹丸的动态矢量造型。
- `src/main.js`：HUD、输入、弹窗、音效和游戏循环。
- `tests/game.test.mjs`：核心规则、连招、Boss 和重开回归测试。

当前面向桌面键盘与鼠标；窄屏可查看页面，但不提供触屏战斗操作。暂未实现局外成长、存档、不同地图场景或实体场景障碍。当前采用可缩放的二维矢量美术与程序动画。装饰地砖、碎石与祭坛均可通行，只有地图边界限制移动。字体在线可用时加载，断网自动使用本机字体，战斗无需外部服务。
